## 2. API 엔드포인트 목록

## API 목록

| Endpoint | Method | 목적 | 주요 파라미터 | 비고 |
|----------|--------|------|--------------|------|
| /api/reservations | POST | 예약 생성 | siteNumber, startDate, endDate, customerName, phoneNumber | 확인코드 반환 |
| /api/reservations | GET | 예약 목록 조회 | date, customerName (선택) | 필터링 가능 |
| /api/reservations/{id} | GET | 예약 상세 조회 | id | - |
| /api/reservations/{id} | PUT | 예약 수정 | id, confirmationCode | 확인코드 필수 |
| /api/reservations/{id} | DELETE | 예약 취소 | id, confirmationCode | 확인코드 필수 |
| /api/reservations/my | GET | 내 예약 조회 | name, phone | 둘 다 필수 |
| /api/reservations/calendar | GET | 월별 캘린더 | year, month, siteId | 모두 필수 |
| /api/sites | GET | 전체 사이트 조회 | - | - |
| /api/sites/{siteId} | GET | 사이트 상세 조회 | siteId | - |
| /api/sites/{siteNumber}/availability | GET | 가용성 확인 | siteNumber, date | - |
| /api/sites/available | GET | 가용 사이트 목록 | date | - |
| /api/sites/search | GET | 기간별 검색 | startDate, endDate, size (선택) | - |
