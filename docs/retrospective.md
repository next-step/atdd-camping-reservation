# 회고

- T-2 인수 테스트 초안: 새로 말해야 했던 제약 0개 (T-1 대비 2개 → 0개로 감소). `test-guide.md`의 두 규칙(도메인 단위 `@Nested` 클래스, `@Sql` 격리)이 그대로 적용되어 추가 지시가 필요 없었음 — 가이드가 효과를 내고 있음.
- T-3 구현 완료 후: 변경한 파일과 diff만 보고 받았는데, 왜 그 지점을 고쳤는지·다른 비슷한 지점(checkAvailability 등)은 왜 그대로 뒀는지가 diff만으로는 파악이 안 돼서 따로 설명을 요청해야 했음. `atdd-implement` 스킬의 "넘어가기 전에" 항목에 구현 후 설명(원인-변경-범위 밖 판단)을 반드시 하도록 추가함 — 다음 구현부터는 재요청 없이 나와야 함.
