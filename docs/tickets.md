내용: 고객센터 신고 — "오늘로부터 30일 넘게 남은 날짜인데 예약이 됩니다."

T-2 예약자 이름 길이 제한 (요구사항에 없음, 코드가 강제)
내용: T-1 작업 중 `ReservationService.createReservation`에서 발견. 예약자 이름이 2자 미만이면 "예약자 이름은 최소 2자 이상이어야 합니다.", 20자 초과면 "예약자 이름은 최대 20자까지 가능합니다."로 거부한다. 이 제한이 실제 요구사항인지, 왜 2자/20자인지 근거가 없다. 확인 필요.
---
T-3 전화번호 형식 제한 (요구사항에 없음, 코드가 강제)
내용: T-1 작업 중 같은 메서드에서 발견. 전화번호를 입력하면(선택 항목인데도) `-`를 제거한 뒤 10~11자리 숫자가 아니면 "전화번호 형식이 올바르지 않습니다."로 거부한다. 이 자릿수 기준이 어디서 온 것인지, 하이픈 포함 다른 형식(국제번호 등)은 어떻게 되는지 확인 필요.

T-4 숙박 기간 최대 30일 제한 (요구사항에 없음, 코드가 강제)
내용: T-1 작업 중 발견. `startDate`~`endDate` 사이 숙박 일수가 30일을 넘으면 "예약 기간은 최대 30일입니다."로 거부한다. T-1이 다루는 "오늘로부터 30일"과는 별개의 규칙인데 숫자가 같아 헷갈리기 쉽다. 이 제한이 실제 요구사항인지 확인 필요. (T-1 수정 시 이 규칙과 혼동하지 않도록 주의)
