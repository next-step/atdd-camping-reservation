# 시스템 분석 결과 - 기술 부채

## 코드 복잡도

| 클래스/메서드 | LOC | 순환복잡도 | 등급 | 문제점 |
|--------------|-----|-----------|------|--------|
| ReservationService | 1,078 | - | Critical | SRP 위반, 8가지 책임 혼재 |
| createReservation() | 213 | ~20 | Critical | 중첩 5단계, 11개 검증 |
| processReservationWithPayment() | 168 | ~18 | Critical | 예약+결제+포인트 혼재 |
| updateReservation() | 74 | ~12 | High | 검증 로직 중복 |
| searchAvailableSites() | 76 | ~12 | High | N+1 쿼리, 중복 로직 |
| getMonthlyCalendar() | 58 | ~8 | High | findAll() 후 필터링 |

## 발견한 기술 부채

### 동시성 문제 (Critical)
- createReservation에 Thread.sleep(100) 존재
- 예약 가능 확인과 저장 사이 Race Condition
- 비관적/낙관적 락 미구현

### NPE 위험 (High)
- SiteResponse.from()에서 split("-")[1] 접근
- siteNumber null 체크 없음

### 코드 중복 (Medium)
- 가격 계산 로직 3곳 중복
- DTO 변환 로직 4곳 중복
- 사이트 크기 판별 2곳 중복
- 날짜 검증 로직 여러 곳 중복

### 하드코딩 (Medium)
- 가격: 50000, 60000, 80000
- 할증률: 1.3, 1.5, 1.7
- 성수기: 7, 8월
- 상태값: "CONFIRMED", "CANCELLED"

### 예외 처리 미흡 (Medium)
- 모든 예외가 RuntimeException
- 25곳 이상에서 발생
- HTTP 상태 코드 매핑 어려움

### Deprecated 코드 (Low)
- CalendarService: 2025년 1분기 제거 예정
- StringUtils.generateRandomCode()

### 성능 문제 (Low)
- findAll() 후 메모리 필터링 4곳
- Random 객체 반복 생성 3곳
- 인덱스 미설정

### 테스트 부재 (Low)
- 테스트 코드 없음
- 동시성 테스트 필요
- 경계값 테스트 필요
