- 규칙   예약 시작일은 오늘로부터 30일 이내여야 한다
  이유   한 달 너머는 운영 일정이 확정되지 않아 예약을 받지 않는다

  예시
  Given  기존 예약과 겹치지 않는 사이트
  When   시작일과 종료일이 오늘 + 29일이다
  Then   201 Created, 확인 코드 발급

  When   시작일과 종료일이 오늘 + 31일이다
  Then   409 "예약 시작일은 오늘로부터 30일 이내여야 합니다."

  질문   정확히 오늘 + 30일인 시작일은 예약 가능 범위에 포함하는가?

---

  규칙  예약할 때 전화번호를 입력해야 한다
  이유  예약 정보를 전달하고 특이사항이 있을 경유 연락하기 위해 전화번호가 필요하다

  예시
  Given  기존 예약과 겹치지 않는 사이트
  When   전화번호를 입력하고 예약을 요청한다
  Then   201 Created, 확인 코드 발급

  When   전화번호를 입력하지 않고 예약을 요청한다
  Then   400 "전화번호를 입력해야 합니다."
