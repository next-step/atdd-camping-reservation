# Top 3 인수 조건

## 1. 동시 예약 처리 (Concurrent Reservation)

### 5W1H 분석

| 구분 | 내용 |
|------|------|
| **Who** | 김철수와 이영희 (두 명의 고객이 동시에) |
| **What** | A-1 캠핑 사이트를 |
| **When** | 2025년 1월 25일 ~ 26일 (동일한 기간에) |
| **Where** | 캠핑 예약 시스템의 예약 API를 통해 |
| **Why** | 동일 사이트의 이중 예약을 방지하여 고객 분쟁과 운영 혼란을 예방하기 위해 |
| **How** | 두 요청이 동시에 도착해도 시스템은 하나만 성공시키고, 나머지는 오류 반환 |

### 인수 조건

> **"두 명의 고객이 동일한 캠핑 사이트를 같은 날짜에 동시에 예약 요청할 경우, 시스템은 정확히 한 건의 예약만 성공시키고, 나머지 요청에는 중복 예약 오류를 반환해야 한다."**

### 검증 포인트

- [ ] 2개의 동시 요청 중 정확히 1개만 성공
- [ ] 성공한 예약에 6자리 확인 코드 발급
- [ ] 실패한 요청에 "해당 기간에 이미 예약이 존재합니다" 메시지 반환
- [ ] 데이터베이스에 해당 기간 예약이 1건만 존재
- [ ] 5개, 10개 동시 요청에도 1건만 성공

## 2. 연박 예약 중간 날짜 검증 (Multi-day Reservation)

### 5W1H 분석

| 구분 | 내용 |
|------|------|
| **Who** | 박민수 (3박 4일 가족 캠핑을 계획하는 고객) |
| **What** | B-5 캠핑 사이트를 |
| **When** | 2025년 1월 24일 ~ 27일 (단, 25~26일에 이미 다른 예약 존재) |
| **Where** | 캠핑 예약 시스템의 사이트 검색 및 예약 기능에서 |
| **Why** | 연박 예약 시 중간 날짜의 기존 예약과 충돌을 방지하기 위해 |
| **How** | 시스템은 예약 기간의 모든 날짜 가용성을 확인하고, 하나라도 예약이 있으면 거부 |

### 인수 조건

> **"고객이 연박 예약을 검색하거나 요청할 때, 시스템은 시작일부터 종료일까지 모든 날짜의 가용성을 확인하여, 중간 날짜에 기존 예약이 있는 경우 해당 사이트를 '예약 불가'로 처리해야 한다."**

### 검증 포인트

- [ ] 중간 날짜에 예약이 있는 사이트가 검색 결과에서 제외
- [ ] 중간 날짜에 예약이 있는 기간에 예약 요청 시 오류 반환
- [ ] 시작일만 겹치는 경우 예약 실패
- [ ] 종료일만 겹치는 경우 예약 실패
- [ ] 기존 예약 전후로 빈 날짜에는 예약 성공

## 3. 취소된 예약 재예약 허용 (Cancelled Reservation Re-booking)

### 5W1H 분석

| 구분 | 내용 |
|------|------|
| **Who** | 최지원 (취소된 자리를 예약하려는 새로운 고객) |
| **What** | A-3 캠핑 사이트를 (원래 홍길동이 예약했다가 취소한 사이트) |
| **When** | 2025년 2월 1일 ~ 2일 (홍길동이 취소한 날짜에) |
| **Where** | 캠핑 예약 시스템에서 |
| **Why** | 취소된 예약은 더 이상 유효하지 않으므로, 해당 기간을 다른 고객이 예약할 수 있어야 함 |
| **How** | 시스템은 가용성 확인 시 CANCELLED 상태의 예약을 제외하고 새 예약을 처리 |

### 인수 조건

> **"기존 예약이 취소된 경우, 해당 날짜와 사이트는 즉시 다른 고객이 예약 가능한 상태가 되어야 하며, 취소된 예약은 중복 예약 검사에서 제외되어야 한다."**

### 검증 포인트

- [ ] CANCELLED 상태 예약이 있는 기간에 새 예약 성공
- [ ] CANCELLED_SAME_DAY 상태 예약이 있는 기간에 새 예약 성공
- [ ] 취소 후 해당 사이트가 가용 사이트 검색 결과에 포함
- [ ] CONFIRMED 상태 예약이 있는 기간에는 여전히 예약 실패
- [ ] 새 예약자에게 새로운 확인 코드 발급
