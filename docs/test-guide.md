- 불필요한 주석은 남기지 않는다.
- 인수 테스트는 실제 서버를 호출하므로 예약이 롤백되지 않는다. 격리는 날짜를 멀리 띄워서 피하지 말고, 서로 다른 사이트를 쓰거나 `@Sql`로 한다.
- 테스트 데이터를 만들기 전 `data.sql`을 읽고, 이미 들어있는 시드 예약과 겹치지 않는 사이트·날짜를 쓴다.
- 이미 쓰인 사이트를 피하는 방법은 `data.sql` 시드를 확인하고 기존 테스트에서 사용되고 있는 사이트들은 피한다.
  - 실제로 쓰인 사이트 목록은 테스트 파일 자체가 최신이니, 헷갈리면 직접 grep해서 확인한다.
- 테스트 코드를 작성할 때에는 null이나 빈 문자열 그리고 확장성을 고려할 수 있도록 테스트를 구성한다.
