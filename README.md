# 초록 캠핑장 예약 시스템

캠핑장 예약 관리를 위한 Spring Boot 기반 웹 애플리케이션입니다.

## 실행

- 자바 17 이상이 필요합니다. 그레이들은 별도 설치 없이 저장소에 포함된 래퍼를 씁니다.
- 기동: `./gradlew bootRun` (기본 8080 포트)

## 작업 문서 (`docs/`)

이 저장소의 작업은 `docs/`의 여섯 파일로 관리합니다. 세 묶음으로 나뉩니다.

**받아서 시작하는 둘** — 뼈대가 채워져 있습니다. 작업하며 자기 방식과 다르면 고쳐 씁니다.

| 파일 | 무엇인가 |
| --- | --- |
| `principles.md` | 어떤 방식으로 일하는가. 저장소가 바뀌어도 통하는 개발 원칙 |
| `plan.md` | 어떤 순서로 하는가. 티켓 하나를 처리하는 네 단계와 이 저장소의 실행 방법 |

**이 저장소의 것을 쌓는 둘** — 빈 상태입니다.

| 파일 | 무엇인가 |
| --- | --- |
| `acceptance-criteria.md` | 무엇이 맞는 동작인가. 확정한 규칙과 예시와 이유 |
| `tickets.md` | 무엇을 해야 하는가. 받은 티켓과 처리하며 발견한 티켓 |

**자기 것을 쌓는 둘** — 빈 상태이고, 저장소가 바뀌어도 자기에게 딸려 갑니다.

| 파일 | 무엇인가 |
| --- | --- |
| `test-guide.md` | 테스트를 어떻게 만드는가. 테스트 초안에 줄 제약을 규칙 한 줄씩 |
| `retrospective.md` | 무엇을 겪었는가 |

무엇을 언제 적는지, 어디까지 채워야 하는지는 미션 문서를 따릅니다.
